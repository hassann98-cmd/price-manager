# تست‌ها

```bash
php tests/run.php      # منطق قیمت‌گذاری (بدون نیاز به وردپرس)
```

- `tests/run.php` — ۲۸ تست برای توابع خالص `WAPM_Price_Engine` و هسته‌ی
  تشخیص تداخل `WAPM_Logger::same_price`. با stub حداقلی وردپرس/ووکامرس اجرا می‌شود.
- تست‌های وابسته به ووکامرس (ذخیره‌ی محصول، لاگ، Rollback، Ajax) در
  [`../docs/TESTING-fa.md`](../docs/TESTING-fa.md) به‌صورت چک‌لیست دستی آمده‌اند.

این پوشه بخشی از افزونه نیست و در پروداکشن لازم نیست.
