# WooCommerce Advanced Price Manager

مدیریت حرفه‌ای قیمت و موجودی محصولات ووکامرس، با مقایسه‌ی قیمت در [ترب](https://torob.com) — بدون رفرش صفحه، با پیش‌نمایش، تاریخچه و بازگردانی.

> این مخزن شامل خودِ افزونه (`woocommerce-advanced-price-manager/`)، بسته‌ی نصب آماده (`price-manager.zip`)، تست‌های واحد (`tests/`) و مستندات فارسی (`docs/`) است.

---

## نصب

**راه ۱ — فایل آماده (پیشنهادی برای سایت واقعی)**

1. `price-manager.zip` را از همین مخزن دانلود کنید.
2. پیشخوان وردپرس → افزونه‌ها → افزودن → بارگذاری افزونه → فایل را انتخاب و نصب کنید.
3. فعال کنید. منوی «مدیریت قیمت» در پیشخوان ظاهر می‌شود.

**راه ۲ — از سورس**

```bash
git clone https://github.com/hassann98-cmd/price-manager.git
cp -r price-manager/woocommerce-advanced-price-manager /path/to/wp-content/plugins/
```

**نیازمندی‌ها:** وردپرس ۶.۰+ · PHP 8.0+ · ووکامرس ۷.۰+ · `mbstring` اختیاری است (بدون آن هم متن فارسی درست مدیریت می‌شود — `WAPM_Str` مسیر جایگزین دارد)

> بسته‌ی zip با `python3 tools/build-zip.py` از سورس ساخته می‌شود و در CI بررسی می‌شود که از کد عقب نماند.

## امکانات

### تغییر قیمت
- درصدی، مبلغ ثابت، یا **قیمت مطلق** («همه‌ی این‌ها دقیقاً ۴۹۹٬۰۰۰»)
- افزایش/کاهش روی قیمت اصلی، قیمت ویژه یا هر دو؛ حفظ درصد تخفیف، حذف قیمت ویژه
- گرد کردن (مضرب ۱۰۰۰/…)، حداقل و حداکثر قیمت، کف قیمت
- دامنه‌ی هدف: همه، دسته، برند، ویژگی، بازه‌ی موجودی، محصولات انتخاب‌شده
- **پیش‌نمایش قبل از اعمال** + Dry Run + تاریخچه + **Rollback با تشخیص تداخل**

### مدیریت قیمت در لیست
- جستجو (نام/SKU)، فیلتر دسته/وضعیت/قیمت/موجودی/نوع/تخفیف‌دار، مرتب‌سازی
- ویرایش inline، حالت ساده/اکسل، ذخیره‌ی خودکار یا دستی
- ستون «آخرین تغییر»، کپی/حذف محصول
- **ویرایش گروهی از لیست** با کشوی تغییر قیمت (پیش‌نمایش + Batch + Undo)
- **انتخاب همه‌ی نتایج** فراتر از صفحه (سقف ۱۰۰۰ با اعلام) و **فیلترهای ذخیره‌شده**

### موجودی
- ویرایش تعداد، کلید «مدیریت انبار»، تغییر وضعیت گروهی
- **کشوی تغییر موجودی**: افزودن/کاهش/تنظیم، تعداد یا درصد، با پیش‌نمایش و Undo
- تاریخچه‌ی کامل تغییرات موجودی + واردات/صادرات CSV + فیلتر «رو به اتمام»

### مقایسه با ترب
- **خروجی CSV مقایسه**: قیمت ما، قیمت ما از دید ترب، ارزان‌ترین رقیب، اختلاف، وضعیت، سن داده و تغییر ۷ روزه‌ی رقیب — با فیلترهای تب لیست
- **صف تأیید تطبیق**: فیلتر/جستجو/صفحه‌بندی و تأیید یا رد گروهی، با نمایش «قیمت ما در برابر ترب»
- سه مسیر داده: بوکمارکلت (از مرورگر خودتان)، فید CSV پنل فروشندگان، و API سرور با بودجه/کول‌داون
- ستون و فیلتر وضعیت (گران‌تر/ارزان‌تر/برابر/فقط ما/داده کهنه)، سن داده، ناسازگاری فید
- قیمت‌گذاری بر اساس ترب: «۲٪ زیر ارزان‌ترین رقیب، اما نه زیر کف قیمت»
- **فیلتر هشدارها**: «⚠ ناسازگاری فید ترب» (قیمت ترب از ما با ووکامرس نمی‌خواند) و «⚠ واحد قیمت مشکوک» (تومان/ریال قاطی شده) — مستقیم در SQL
- **تاریخچه‌ی قیمت رقیب**: ۳۰ نقطه‌ی آخر تغییر قیمت، خط روند در ستون ترب و نمودار کوچک در کشو
- **هم‌تراز با ترب**: در ستون ترب هر محصول، دکمه‌ی «هم‌تراز» → مقدار زیربرش (درصد یا تومان) → پیش‌نمایش → اعمال با Batch و بازگردانی. هرگز قیمت را گران نمی‌کند و دلیل رد‌شدن را فارسی می‌گوید

جزئیات فنی: [`docs/TOROB-API-fa.md`](docs/TOROB-API-fa.md)

## توسعه

```bash
# تست‌های واحد (بدون وردپرس؛ از stub استفاده می‌کنند)
php tests/run.php

# لینت
find woocommerce-advanced-price-manager -name '*.php' -exec php -l {} \;
for f in woocommerce-advanced-price-manager/assets/js/*.js; do node --check "$f"; done

# بازتولید فایل ترجمه و بسته‌ی نصب
python3 tools/make-pot.py
python3 tools/build-zip.py

# CSS تیلویند (فقط اگر کلاس‌ها را عوض کردید)
npm ci
npm run build:css

# بررسی JS: اعلان تکراری + تست دودی در jsdom (رندر لیست، انتخاب گروهی، کشوها)
npm run lint:js
npm run smoke:js

# بررسی تازه بودن (همان چیزی که CI اجرا می‌کند)
python3 tools/make-pot.py --check
npm run check:css
python3 tools/build-zip.py --check
```

**درباره‌ی ساختار JS:** کد پیشخوان به ماژول‌های کوچک تفکیک شده و از طریق
`window.WAPMUI` با هم حرف می‌زنند (ترتیب لود در `enqueue` تضمین شده است).
`npm run smoke:js` با jsdom یک صفحه‌ی وردپرس را شبیه‌سازی می‌کند و مسیرهای
حساس (رندر لیست، انتخاب گروهی، کشوها، تب‌ها) را می‌آزماید.

**درباره‌ی Tailwind:** استایل‌ها یک‌بار و در این مخزن ساخته می‌شوند
(`assets/css/tailwind.css`) و افزونه همان فایل را لود می‌کند؛ Play CDN در
پروداکشن استفاده نمی‌شود. اگر کلاس تیلویندی در `class-admin.php` یا
`admin.js` اضافه/حذف کردید، `npm run build:css` را اجرا کنید — CI با
`npm run check:css` تفاوت را می‌گیرد.

CI (`.github/workflows/ci.yml`) روی هر push و PR: لینت PHP روی ۸.۰ و ۸.۳، تست واحد، بررسی سینتکس JS، و بررسی تازه‌بودن POT و zip.

## داده و حذف افزونه

- **غیرفعال‌سازی**: هیچ داده‌ای پاک نمی‌شود؛ فقط کرون ساعتانه برداشته می‌شود.
- **حذف افزونه**: `uninstall.php` تنظیمات، قوانین، زمان‌بندی‌ها، متاهای ترب روی محصولات، فیلترهای ذخیره‌شده و جدول‌های تاریخچه را پاک می‌کند (مالتی‌سایت هم پشتیبانی می‌شود).
- اگر می‌خواهید داده بماند:
  ```php
  // wp-config.php
  define( 'WAPM_KEEP_DATA_ON_UNINSTALL', true );
  ```
